# Trilha TRT4 2026 — site estático

Arquivos: `index.html` (o site), `questoes.js` (1.010 questões), `pilulas.js` (2.476 pílulas), `config.js` (dados do Supabase), `supabase.js` (biblioteca do Supabase) e `vercel.json`.

## Publicar no Vercel
Suba todos os arquivos desta pasta no repositório (ou rode `npx vercel --prod` dentro dela).

## Login e progresso
O progresso é salvo no Supabase quando a pessoa entra com o e-mail (Meu progresso > Enviar link de acesso).
O script da tabela está em `supabase.sql` (já aplicado no projeto).
